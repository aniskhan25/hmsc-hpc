# Simulated Spatial Random-Slope Validation

This project validates native Python-only spatial random-slope sampling for
full spatial, GPP, and NNGP random levels. The data are generated by
`pyhmsc.simulate.simulate_spatial_random_slope_effect_data` with
`n_sites=49`, `n_species=5`, and `seed=41`.

The latent random effect is spatially structured over one site-level random
level. `slope_env` modulates the latent factor through species-specific
`Lambda` loadings, so validation can check fixed-effect signs, posterior
predictive coverage, `Eta` recovery, and `Lambda` intercept/slope recovery.
