# Neural-HMSC Fixed Poisson Benchmark

This project directory is a Milestone 0 benchmark configuration for the
amortized Neural-HMSC feature branch.

It does not contain generated CSV/HDF5 data yet. Later milestones should use
`benchmark.yaml` to generate reproducible fixed-effect Poisson validation data.

This is a secondary target. It should be implemented after Gaussian and probit
fixed-effect posterior behavior is understood.
