# Neural-HMSC Fixed Probit Benchmark

This project directory is a Milestone 0 benchmark configuration for the
amortized Neural-HMSC feature branch.

It does not contain generated CSV/HDF5 data yet. Later milestones should use
`benchmark.yaml` to generate reproducible fixed-effect probit validation data.

This is a secondary target. It should be implemented only after the fixed
Gaussian `Beta` posterior prototype passes the benchmark protocol.
