# Simulated Spatial Multi-Factor Eta Validation

This project validates the native NNGP Eta updater for more than one latent factor. It uses a normal response, two spatial latent factors, known species loadings, and an NNGP random level with `nf=2`.

- `n_sites=64`
- `n_species=8`
- `n_factors=2`
- `spatial_ranges=(0.20, 0.45)`
- `spatial_sd=1.2`
- `lambda_scale=1.1`
- `noise_sd=0.08`
- `distr="normal"`
- `seed=211`
